# Exercício com Switch em Java

Exercício desenvolvido em Java para praticar o uso da estrutura condicional `switch`.

## Objetivo

Receber um valor informado pelo usuário e executar uma ação de acordo com a opção escolhida utilizando `switch`.

## Tecnologias utilizadas

- Java
- Scanner
- Switch / Case

## Como executar

1. Abra o projeto em uma IDE Java.
2. Execute o arquivo principal.
3. Digite uma das opções solicitadas pelo programa.
4. O programa exibirá o resultado correspondente.

## Exemplo

```java
switch (opcao) {
    case 1:
        System.out.println("Opção 1");
        break;

    case 2:
        System.out.println("Opção 2");
        break;

    default:
        System.out.println("Opção inválida");
}
```
